Condiciones de Uso

Las presentes Condiciones de Uso regulan el acceso y utilización del sitio web de Lessandra Terapias.

El acceso y navegación por este sitio web implica la aceptación de las presentes condiciones en los términos que se indican a continuación.

1. Titular del sitio web

El sitio web corresponde a Lessandra Terapias y tiene como finalidad proporcionar información sobre los servicios ofrecidos, facilitar el contacto con la profesional y permitir la solicitud de citas.

Los datos de contacto disponibles para las personas usuarias se encuentran publicados en diferentes apartados de este sitio web.

2. Finalidad del sitio web

Esta página web tiene carácter principalmente informativo.

A través de ella se proporciona información sobre las diferentes terapias y servicios ofrecidos por Lessandra Terapias y se facilitan diferentes medios de contacto, entre ellos WhatsApp, correo electrónico y formulario de solicitud de cita.

La información publicada en la web tiene carácter orientativo y puede ser modificada, actualizada o retirada cuando resulte necesario.

3. Uso correcto del sitio web

La persona usuaria se compromete a utilizar este sitio web de forma lícita, responsable y respetuosa con la legislación vigente, los derechos de terceros y las presentes condiciones.

Queda prohibido utilizar la web para realizar actividades que puedan perjudicar, sobrecargar, dañar o impedir el funcionamiento normal del sitio web o de sus servicios.

Asimismo, no deberán introducirse mediante los formularios contenidos ilícitos, ofensivos, fraudulentos o que vulneren los derechos de terceras personas.

4. Solicitud de citas

El formulario disponible en la web permite realizar una solicitud de información o una petición de cita.

El envío de una solicitud no implica por sí mismo la confirmación de una cita. La disponibilidad y la confirmación deberán ser acordadas posteriormente con Lessandra Terapias.

La persona usuaria deberá proporcionar información correcta y actualizada cuando utilice los medios de contacto disponibles.

Los contenidos de este sitio web, incluyendo textos, fotografías, imágenes, logotipos, diseños, elementos gráficos y demás materiales, están destinados a proporcionar información sobre Lessandra Terapias y sus servicios.

No está permitido reproducir, distribuir, modificar, comunicar públicamente o utilizar con fines comerciales los contenidos de esta web sin la autorización correspondiente, salvo cuando la legislación aplicable permita expresamente dicho uso.

Algunas imágenes, fotografías o contenidos mostrados en el sitio web pueden proceder de servicios o plataformas externas o ser utilizados con las correspondientes autorizaciones.

Estas reseñas pueden incluir el nombre mostrado por el autor, fotografía de perfil, valoración y contenido de la opinión, de acuerdo con la información que el propio usuario haya publicado en Google.
